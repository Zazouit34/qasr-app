# Qasr App — Event Venue Management Dashboard 🏰📊

**Qasr App** is an all-in-one operations dashboard built specifically for event venues and wedding halls. It bridges the gap between client hospitality and internal staff operations by unifying booking data, financial transactions, and employee management into a single platform.

## 🚀 Key Features

### 👤 Client & Financial Management
* **Client Tracking:** Keep tabs on reservations, active events, and client history.
* **Automated Calculations:** Effortlessly compute booking packages, extras, and discounts.
* **Receipt Generation:** Create and send digital receipts directly to clients upon payment.

### 👥 Staff & Payroll Management
* **Time & Attendance:** Monitor employee check-in/check-out hours.
* **Automated Payroll:** Automatically calculate employee salaries based on verified logged hours.
